## Git

- Never commit without my permission.
- NEVER push.
- Never commit to the main or master branches
- Keep commit messages focused and describe *why* a change was made, not just *what*
  changed.
- Don't commit generated output, credentials, tokens, or data files unless the
  project's `.gitignore` already tracks that pattern intentionally.

## Provenance

- Log a summary of all work in <plan-name>-log files
- Each prompt I give and each question I answer should have an entry in the log file.
- Each entry should start with the date and time, followed by the prompt or question
  answers and then a summary of what you did and why. Keep this short, especially if the plan was followed. You can refer to sections of the plan, etc.
